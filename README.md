# Power Platform DevOps Studio

**Power Platform DevOps Studio** is a modern browser-based UI for managing DevOps workflows for Microsoft Power Platform solutions.

## Download

Download the latest release from the [Releases](https://github.com/dylanhaskins/PowerPlatform-DevOpsStudio-Releases/releases) page.

1. Download `PowerPlatform-DevOpsStudio-win-x64.zip`
2. Extract `PowerPlatform-DevOpsStudio.exe` anywhere on your machine (e.g. `C:\Tools\`)
3. Double-click to run — a browser window opens automatically
4. No Node.js or npm installation required

## Requirements

- Windows 10/11 (x64)
- [Power Platform CLI (pac)](https://aka.ms/PowerAppsCLI) — for solution operations
- [Azure CLI (az)](https://aka.ms/installazurecliwindows) — for Key Vault / Azure operations
- [Git](https://git-scm.com/download/win) — for source control features

## Features

- Export & unpack Power Platform solutions
- Manage Azure DevOps source control and pipelines
- Configure Service Principals and Azure Key Vault
- Run deployments locally or via Azure DevOps pipelines
- Generate TypeScript types from Dataverse

## Updates

The app checks for new releases automatically and will notify you with a download link when a newer version is available.
